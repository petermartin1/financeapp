# Finance App Development Roadmap

## Completed Features
- [x] App lock/PIN security
- [x] Accounts management (checking, savings, credit card, investment)
- [x] Transactions with search/filter
- [x] Category management
- [x] File import (OFX/QFX/CSV)
- [x] OFX Direct Connect (Alliant, Fidelity)
- [x] Account reconciliation
- [x] Scheduled transactions
- [x] Reports & Charts (spending by category, income vs expenses, net worth)
- [x] Budgeting (monthly budgets, spending tracking, progress bars)
- [x] SQLCipher database encryption
- [x] Data backup & export (CSV/OFX)
- [x] Biometric authentication (Touch ID / Face ID on iOS)
- [x] Transfer support (link transactions, auto-create matching entries)
- [x] Payee Management (auto-categorization rules, merge duplicates, spending history)
- [x] Investment Tracking (portfolio overview, cost basis, gain/loss, asset allocation)
- [x] Data Import Enhancements (QIF support, CSV column mapping, import preview)
- [x] Transaction Improvements (split transactions, tags, bulk operations)
- [x] Dark mode
- [x] Customizable dashboard
- [x] Keyboard shortcuts (desktop)
- [x] Transaction templates

---

## Upcoming Features

### 1. Goals and Savings Targets
- Create financial goals (emergency fund, vacation, etc.)
- Set target amounts and deadlines
- Link to specific accounts
- Track progress with visual indicators

### 2. Loan/Mortgage Tracking
- Add loan accounts with principal, interest rate, term
- Amortization schedule calculation
- Track payments vs principal/interest split
- Payoff projections and extra payment scenarios

### 3. Multi-currency Support
- Support multiple currencies per account
- Manual or automatic exchange rates
- Currency conversion in reports
- Base currency for net worth calculations

### 4. Tax Reporting
- Categorize tax-deductible expenses
- Generate annual tax summaries
- Export tax-related transactions
- Track deductions by category

### 5. Mobile Sync
- Cloud backend for data synchronization
- Sync across desktop/mobile devices
- Conflict resolution
- End-to-end encryption
